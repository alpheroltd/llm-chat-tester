Testing whether a bot keeps its rules and its secrets.

## What this lesson will cover

- What prompt injection and data leakage are, and why they matter
- Why rules written in a prompt aren't access control
- Layered defences (instructions, input and output filters) and their limits
- Agreeing scope before security testing a client's bot
- Reporting a finding so developers can reproduce and fix it
